RFP AI

نظام طورناه لصالح شركة BeamData، يستخرج 24 حقلًا منظمًا من ملفات طلبات العروض (RFP). قارنّا نموذجين ذاتيي الاستضافة، Granite-8B وQwen-4B، مع OpenAI عبر 360 تقييمًا. نُشرت النماذج بـ vLLM على Kubernetes داخل حاويات Docker، وتمت مراقبتها بـ Prometheus وGrafana. أضفنا تقسيم الملفات، والتحقق من JSON وإصلاحه، واختيار أفضل إجابة، وواجهة Streamlit.A system built for BeamData that extracts 24 structured fields from RFP documents. We benchmarked two self-hosted models, Granite-8B and Qwen-4B, against OpenAI across 360 model-field evaluations. Models run on vLLM and Kubernetes in Docker containers, monitored with Prometheus and Grafana. The pipeline adds PDF chunking, JSON validation and recovery, candidate selection and a Streamlit interface.
